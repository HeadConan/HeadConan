SPY × FAMILY — image asset slots
=================================

This folder holds the SPY x FAMILY demo's poster images.

Slot convention
---------------
For each character the demo looks for, in this order:

1.  `assets/worlds/spy-family/<name>.png`  <- YOUR licensed/official image (optional)
2.  `assets/worlds/spy-family/<name>.svg`   <- procedural Neubrutalist poster (bundled, always present)

If you place a `.png` here, the demo shows it automatically. No code changes needed.
If the `.png` is missing, the bundled `.svg` poster is shown instead.

Expected filenames:
    loid.png / loid.svg
    yor.png  / yor.svg
    anya.png / anya.svg
    bond.png / bond.svg
