# Scenario Layout Analysis: World Director & Ontological Architect

## 1. Experiential Goals
Authoring and directing a universe requires omniscient visibility into all ground-truth facts, active entity memories, underlying metaphysical laws (axioms), and event injection controls.

## 2. Spatial Composition
* **Primary Stage (60%)**: Ontological Rule Graph & Crisis Spawning Matrix—node graph of all entities, facts, and metaphysical laws with direct mutation controls.
* **Satellite Rail (30%)**: Selected Entity Deep Inspector—viewing hidden agendas, raw memories, and epistemic awareness boundaries.
* **Ambient Monitor (10%)**: Simulation Invariant Health, System Anomaly Rate, AI Agent Deliberation Latency.
* **Action Dock**: Directorial commands ("Trigger regional plague outbreak", "Invert King's allegiance to hostile", "Reveal hidden heir lineage to public").
