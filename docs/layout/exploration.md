# Scenario Layout Analysis: Spatial Exploration & Tactical Reconnaissance

## 1. Experiential Goals
Exploration centers spatial orientation, territorial control, movement paths, environmental hazards, and discovery of nearby entities or resources.

## 2. Spatial Composition
* **Primary Stage (70%)**: Interactive 2D Vector Map / Architectural Blueprint with coordinate nodes, fog-of-war shading, route paths, and dynamic territory outlines.
* **Satellite Rail (20%)**: Selected Location Inspector—atmospheric description, spatial affordances, co-present NPCs, and local dangers.
* **Ambient Monitor (10%)**: Weather conditions, time-of-day clock, regional danger meter.
* **Action Dock**: Movement directives ("Infiltrate eastern guard tower", "Establish campsite", "Survey perimeter").
