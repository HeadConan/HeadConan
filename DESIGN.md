# Design Principles & Visual System — HeadConan

## 1. Core Principles

1. **Imagination Before Interface**: The interface serves as a cognitive telescope, not an administrative dashboard.
2. **Minimum Sufficient Reality**: Generate only enough structure to spark exploration.
3. **UI Represents World State**: Every visual component reflects an underlying simulation entity.
4. **World State is Independent of UI**: Data is never stored inside visual views.
5. **AI Proposes Structure, Deterministic Code Renders It**: Strict component safety and styling elegance.
6. **No AI Slop / No Unsolicited Clichés**:
   - No generic purple-to-blue gradient text.
   - No arbitrary rainbow neon glows.
   - No monotonous 3-column equal cards.
   - No promotional hero banners in the working application.
7. **Preserve User Agency**: The user drives the world's narrative direction.
8. **Cinematic, Restrained Atmosphere**:
   - Deep void canvas `#08090d` with crisp `#131622` card containers.
   - Typography pairing: *Cinzel* / *Newsreader* for atmospheric world headers; *Inter* for crisp body; *JetBrains Mono* for system metadata and telemetry.
   - Micro-interactions: subtle pulse indicators, staggered genesis sequence, soundless fluid transitions.
